# Chapter Review Template — The Luna Who Said No

> Adapted from webnovel-writer's review pipeline + novel-skills' 4-pass revision workflow.
> Run AFTER drafting, BEFORE publishing. Each chapter must pass all gates.

## The 4-Pass Revision (novel-skills workflow, adapted)

```
1. HUMANIZER      → strip AI tells, break formulaic syntax, ground emotion
2. DIALOGUE       → subtext, voice distinctiveness, unspoken tension
3. PROSE          → line edit, show-don't-tell, sentence rhythm
4. CONTINUITY     → physical movement, injuries, timeline, world-rule alignment
```

## Pass 1 — Humanizer

- [ ] Zero signature AI vocabulary (see anti-ai-checklist)
- [ ] No "Romance-AI Trinity" overuse (breath caught / jaw clenched / eyes widened ≤1 combined)
- [ ] Paragraph lengths vary drastically (1-line paragraphs mixed with long blocks)
- [ ] No tidy paragraph resolutions ("...and she finally understood")
- [ ] Passes the humanity test: sounds like lived experience, not generated

## Pass 2 — Dialogue

- [ ] Elara / Kael / Selene identifiable by voice alone (blind test)
- [ ] No character explains the plot to another character
- [ ] Subtext present: someone dodges, trails off, or answers a different question
- [ ] Dialogue tags ≤30% "said"; rest are action beats
- [ ] No adverb-crutch tags (softly/slowly/gently)

## Pass 3 — Prose & Pacing

- [ ] Information density: every ~1000 words advances ≥1 plot point (romance-adapted: new information, relationship shift, emotional turn, foreshadowing planted/paid off, conflict introduced/escalated)
- [ ] At least 1 emotional beat per chapter (tension spike, tender moment, power reversal, revelation)
- [ ] Hook in first 300 words — no "it was a sunny day" openings
- [ ] Chapter ends on action / dialogue / image — never on summary or resolved emotion
- [ ] Sensory writing via smell, sound, heartbeat (werewolf senses) — not adjective piles

## Pass 4 — Continuity

- [ ] Character behavior matches dossier (see consistency-ledger.md)
- [ ] No new world rule contradicts established rules
- [ ] Injuries / physical states carry over from previous chapters
- [ ] Timeline is coherent (the 30-day countdown: what day is it?)
- [ ] All foreshadowing planted is logged in the ledger

## Hard Quality Gates (novel-skills revise-chapter)

- [ ] AI pattern audit: zero signature AI vocabulary
- [ ] Blind dialogue test passed (cover names → voices still distinct)
- [ ] Filter words (saw/felt/seemed/appeared) reduced by >80% vs. draft
- [ ] Dialogue tags: primarily "said/asked" + action beats, adverb tags deleted
- [ ] Zero unaddressed physical movement / inventory / timeline contradictions
- [ ] Opening type differs from previous 2 chapters (rotation check)
